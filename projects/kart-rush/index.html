Kart Rush

A 3D kart racer designed for the phone. It runs straight in the browser and works offline.

Play now itch.io

01 Overview

Kart Rush is a 3D kart racer in the spirit of Mario Kart. It plays with touch controls, installs to the iPhone home screen, and once installed it works without internet.

  • Tracks8 tracks, each with its own theme, elevation and banking.
  • Drivers8 characters, each with its own animated model.
  • RacingAI rivals with different personalities, items, boost pads and drifting.
  • SoundAll audio is synthesised with WebAudio; there are no sound files.

02 How it's built

JavaScriptThree.jscannon-esWebAudioService WorkerPWANo build step

The game is plain JavaScript, with Three.js for rendering and cannon-es for vehicle physics. There is no build step: it is static files served by GitHub Pages, and a service worker caches everything for offline play.

Steering with digital buttons took real work: ramped input, a steering lock that shrinks with speed, and a stability assist that runs on every physics sub-step so the kart doesn't spin out at speed.

03 How I tune it

Races I play on my phone send telemetry (events plus one-second samples) to a local server, and I analyse that data to tune the rival AI and difficulty. It gives better data than automated tests.
