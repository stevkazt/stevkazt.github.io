Active Directory Lab

A virtualized Windows Server environment that simulates corporate IT: a domain controller, a joined workstation, structured users and security policies.

01 Overview

I built the lab to practise the core of enterprise IT support: centralized user management, security policies and network resource administration.

02 Architecture

  • ServerWindows Server 2022 as the domain controller, running the DNS, DHCP and AD DS roles.
  • ClientA workstation joined to the domain.
  • NetworkAn isolated NAT network simulating a corporate LAN.

03 Implementation

Once the domain controller was up, I organised the directory for growth: Organizational Units for the departments (IT, Finance, Sales); a PowerShell script to bulk-import users with standardized naming; and Group Policy for password complexity and restricted Control Panel access for non-admin users.

04 Troubleshooting

The client wouldn't join the domain because it was using the router's DNS instead of the domain controller's. Pointing its IPv4 DNS at the controller's static IP fixed it, and made the dependency between DNS and Active Directory concrete.

05 Result

A working Windows domain with managed users, groups and policies.
